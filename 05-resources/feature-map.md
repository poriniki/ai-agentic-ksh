# Feature Map: Claude and ChatGPT

The concepts transfer between tools; only the names differ. **Feature names and plan availability change often. Check this table against your company's actual tools and plan before the session** and delete rows you can't use.

| What you need | Claude | ChatGPT | Use it for | Pro habit |
| --- | --- | --- | --- | --- |
| A persistent workspace with files + instructions | Projects | Projects; custom GPTs | Recurring areas of work: reports, brand content, proposals | One Project per recurring area; an owner keeps files current |
| Always-on preferences | Profile preferences, Styles, Memory | Custom instructions, Memory | Your role, writing preferences, language | Review what memory has stored; turn off for sensitive work |
| Work on documents | File upload (PDF, Word, text…) | File upload | Summarise, compare, extract, check against criteria | Ask it to quote the passage behind each claim |
| Real calculations and charts | Code execution / file creation | Data analysis | Spreadsheet analysis, charts, Excel outputs | "Describe the data first"; recompute key numbers |
| A living document or mini-tool | Artifacts | Canvas | Proposals, tables, calculators, templates, dashboards | Test calculators with known answers |
| Current info with sources | Web search; Research | Search; Deep research | Benchmarks, competitor scans, regulation summaries | Source table; open the key sources |
| Company tools | Connectors (e.g. Google Drive, Gmail, Slack…) | Connectors / apps | Work on live documents and email | Only if approved; same data rules apply |
| Multi-step work done for you | Cowork; Claude in Chrome | Agent mode | Multi-step file and browser tasks | Review its plan first; checkpoint before anything external |

## Choosing the right level

| Task | Ladder level | Feature |
| --- | --- | --- |
| Quick rewrite, one-off question | 1–2 Ask / Brief | Plain chat |
| Recurring content in a fixed style | 3 Equip | Project |
| Monthly analysis of a spreadsheet | 3–4 Equip / Chain | Project + data analysis, a series of chats |
| Desk research on a market | 3–5 | Research mode |
| Multi-step task across many files | 5 Delegate | Cowork / agent mode, with checkpoints |
