# Learning Path After the Workshop

A self-paced path for participants who want to go deeper, condensed from the full plan in [`00-reference/ai-agents-learning-plan.md`](../00-reference/ai-agents-learning-plan.md). Everything is free, in English, and needs no coding. Plan for 6–8 weeks at 3–5 hours a week.

## How it connects to the workshop

| Workshop module | Go deeper with | Phase |
| --- | --- | --- |
| M1 How AI really works | AI Capabilities and Limitations; Generative AI for Everyone | 1 |
| M2 The 4Ds and the pro brief | AI Fluency: Framework & Foundations; Anthropic prompt engineering guide | 2 |
| M3 From chats to a workspace | Claude 101 | 2 |
| M4 Workflows and agents | Building effective agents; Barry Zhang's talk; Introduction to Claude Cowork | 3 |
| M5 Let AI ask the questions | Prompt Engineering for ChatGPT (weeks 3 and 6); A Prompt Pattern Catalog | 4 |
| M6 Managing AI in a team | One Useful Thing (Ethan Mollick); AI for Everyone (business side) | ongoing |

## Start this week

1. [AI Fluency: Framework & Foundations](https://anthropic.skilljar.com/ai-fluency-framework-foundations) (Anthropic Academy, a few hours): the full version of the 4Ds; free certificate.

## Phase 1 — AI fundamentals (weeks 1–2)

- [AI Capabilities and Limitations](https://anthropic.skilljar.com/ai-capabilities-and-limitations) — Anthropic Academy, ~1–2 h
- [Generative AI for Everyone](https://www.deeplearning.ai/courses/generative-ai-for-everyone) — DeepLearning.AI (Andrew Ng), ~5 h
- Optional: [Elements of AI](https://www.elementsofai.com/) — University of Helsinki, vendor-neutral basics

## Phase 2 — Using assistants well (weeks 2–3)

- [AI Fluency: Framework & Foundations](https://anthropic.skilljar.com/ai-fluency-framework-foundations) — Anthropic Academy
- [Claude 101](https://anthropic.skilljar.com/claude-101) — Anthropic Academy, ~1–2 h
- [Prompt engineering guide](https://docs.claude.com/en/docs/build-with-claude/prompt-engineering/overview) — Anthropic docs; read the concepts, skip the API code
- [Prompt Engineering for ChatGPT](https://www.coursera.org/learn/prompt-engineering) — Vanderbilt, Coursera, free to audit
- Optional: [OpenAI Academy](https://academy.openai.com/) — AI Foundations

## Phase 3 — Process design with AI and agents (weeks 4–5)

- [Building effective agents](https://www.anthropic.com/research/building-effective-agents) — Anthropic, ~30 min; focus on the diagrams
- [How We Build Effective Agents — Barry Zhang](https://ai.engineer/talks/effective-ai-agents) — ~15 min; when *not* to use an agent
- [Introduction to Claude Cowork](https://anthropic.skilljar.com/introduction-to-claude-cowork) — Anthropic Academy
- Optional: [AI Fluency for Builders](https://anthropic.skilljar.com/ai-fluency-for-builders) — Anthropic Academy

## Phase 4 — Q&A and requirements discovery (weeks 6–7)

- [Prompt Engineering for ChatGPT](https://www.coursera.org/learn/prompt-engineering), weeks 3 and 6 — Flipped Interaction, Question Refinement, Cognitive Verifier
- [A Prompt Pattern Catalog](https://arxiv.org/abs/2302.11382) — Vanderbilt paper; read the pattern descriptions only
- Optional: [Requirement Gathering and Analysis with GenAI](https://www.coursera.org/learn/requirement-gathering-and-analysis-with-genai-training) — Coursera (check whether audit is available)

## Staying current

- [One Useful Thing](https://www.oneusefulthing.org/) — Ethan Mollick's newsletter; practical and research-based
- [Anthropic Academy](https://www.anthropic.com/learn) — new courses appear regularly
- [OpenAI Academy](https://academy.openai.com/) — free live and on-demand sessions

## Practice beats reading

Spend at least half your learning time on your own real tasks. The homework and projects from this workshop cover the practice exercises from the original plan; repeat them with new tasks as you progress.
