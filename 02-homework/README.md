# Homework — Overview

*Course: The AI-Powered Professional*

Each team has its own homework file. The tasks practise the features and thinking habits from the session on realistic work from your own field.

| File | For |
| --- | --- |
| [marketing.md](marketing.md) | Marketing team |
| [business.md](business.md) | Business team (business development, strategy, sales ops, product, operations) |
| [finance.md](finance.md) | Finance team (FP&A, accounting, controlling, treasury) |

If your role doesn't fit any of these, pick the closest file and adapt the scenarios to your own work.

## What every homework file contains

Seven tasks. Each task practises one feature and one of the 4Ds:

| # | Practises | Feature | Ladder level |
| --- | --- | --- | --- |
| 1 | Discernment: spotting confident errors | Two assistants, web search | 1 |
| 2 | Description: the 6-part brief | Plain chat | 2 |
| 3 | Equip: persistent context | Projects + instructions | 3 |
| 4 | Working with data and documents | File upload + data analysis | 3 |
| 5 | Building, not just chatting | Artifacts / Canvas | 3 |
| 6 | Research with sources | Web search / Research | 3–5 |
| 7 | Flipped interaction + workflow thinking | Interview-me, assumption check, critique in a new chat | 4 |

**Required:** tasks 1, 2, 3 and any two of 4–7. **Recommended:** all seven.
**Time:** about 30 minutes per task, 3–4 hours in total.
**Due:** [date — fill in]
**Submit to:** [folder / email / channel — fill in]

## Rules

1. **Data:** follow the data traffic light from the session. If you're not sure your data is allowed, use AI-generated sample data. Ask: *"Generate a realistic but fictional [CSV / document] for a [company type] with [columns / sections]. Include a few realistic issues."*
2. **Real work where possible:** the closer the task is to your actual job, the more useful it is. Adapt the scenario.
3. **Honesty over polish:** a task where the AI failed and you explain why is worth as much as one that worked.

## What to submit: the AI work log

For each task you complete, add one entry to a single document called `homework-log-[your-name].md` (or a Word/Google Doc). Use this template:

```markdown
## Task [number] — [title]

**Tool and features used:** (e.g. Claude, Project + file upload)

**What I asked (final prompt or a summary of the chat):**
> ...

**What I got (short excerpt or screenshot):**
...

**What I checked and how:**
- ...

**What I changed or rejected, and why:**
- ...

**Time: without AI (estimate) / with AI (including checking):** __ min / __ min

**One thing I learned:**
...
```

## How the homework is assessed

The homework is feedback, not a grade. The facilitator looks at:

| Criterion | What good looks like |
| --- | --- |
| Description | Prompts use the 6-part brief where it matters; examples are given |
| Discernment | Specific checks are described (which numbers, which sources), not just "I checked it" |
| Feature use | The feature was actually used and its value or limits are explained |
| Reflection | Honest notes on what failed and what you'd do differently |
